Streamlit Dashboard Implementation Summary
The Streamlit dashboard provides an interactive interface for the Fundus and OCT image classification system. It includes four pages: Overview, Results, Predictions, and About. The app loads pre-trained models (Fundus and OCT) with caching, along with their feature selectors and cross-validation scores. It also loads the original feature names (139 features) from saved training data files to ensure feature extraction matches training.
The prediction pipeline handles single-image classification: it accepts uploaded Fundus or OCT images, extracts features using the same alternative feature extractor (scikit-image/scipy) used during training, ensures features are in the same order as training by using the saved feature names, applies the saved feature selector to reduce from 139 to 50 features, and generates predictions with class probabilities. The app supports single-modality predictions (Fundus or OCT) and multi-modal fusion when both images are provided, with adjustable fusion weights (default 30% Fundus, 70% OCT) via sidebar sliders.
The visualization components display individual predictions with class names and probability distributions as horizontal bar charts, show fused predictions when both modalities are available, indicate agreement or disagreement between models, and present performance metrics including cross-validation scores, confusion matrices (if available), and model comparison charts. The app includes error handling for feature extraction mismatches, automatic re-extraction when feature counts don't match, and informative messages throughout the prediction process. The interface uses custom CSS styling, a wide layout, and a sidebar navigation system for easy access to different sections of the dashboard.
